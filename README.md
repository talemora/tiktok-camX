# Tiktok CameraX backend for Android
Replaces stock Camera2/Camera1 API in TikTok on supported devices

### Working
1. Camera (Front/Back)
2. Filters
3. Publishing & Editing video inside TikTok

### Not Working (!)
1. Zooming (Both camera’s)

### Known bugs
1. Backend freezes after choosing sound in expanded sound selector
2. Effects/Filters won’t display after posting video (same for other users)
2.1 People won’t be able to see what filter you used

### Tested on
* Pixel 9 (tokay) / Pixel 9 Pro (caiman)
* Galaxy S23 Ultra (dm3q)
* Galaxy S25 Ultra (pa3q)
